# آزمون سنجش اعتماد کودکان

نرم‌افزار پژوهشی برای سنجش اعتماد در کودکان پایه اول و دوم ابتدایی.

## قابلیت‌ها

- انتخاب مجموعه ویدئوهای دخترانه یا پسرانه
- پخش ۸ ویدئو به ترتیب تصادفی
- ثبت پاسخ به ۴ سؤال پس از هر ویدئو
- زمان‌بندی پاسخ‌ها
- صفحه استراحت ۳۰ ثانیه‌ای بین ویدئوهای ۴ و ۵
- ذخیره خودکار داده‌ها در فایل Excel
- نمره‌گذاری خودکار بر اساس مدل طیفی (بی‌اعتمادی، اعتماد معرفتی، ساده‌لوحی)
